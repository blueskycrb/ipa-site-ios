登录 Apple ID

账号密码只会传给本机的 ipatool，凭据由 ipatool 保存在系统钥匙串中。可以添加多个 Apple ID，登录后会切换到这个账号；同一个 Apple ID 再登录一次就是重新登录。

历史版本

最新的 5 个版本会自动显示版本号，其余点「查看」（每个版本要问 Apple，几秒到一分钟，查过的会记住）。在下面输入版本号（如 14.8.40、14.8）或日期（如 2026-09）后回车，可以直接找到对应版本。

解密凭证

App Store 原版 IPA 是加密的（重签后会闪退），要用下载它的 Apple ID 的凭证解密：就是 fairplay-decrypt 从越狱设备导出的 16 字节 credential.bin。每个 Apple ID 一个，建议按地区命名，例如 US、CN。解密后的 IPA 可以证书签名或用 TrollStore 安装。
