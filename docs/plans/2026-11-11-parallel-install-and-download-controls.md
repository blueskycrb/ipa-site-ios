# 并存安装与下载任务控制

用户需求：保留手机上的 App Store 官方版，另装解密后重签的副本；在下载任务页面暂停、继续、取消和删除任务。

## 并存安装

- iPhone 与网页的签名入口提供可选的并存开关和副本名称；默认保留原标识。
- 通配描述文件依据原 Bundle ID 生成稳定的新标识。受限通配文件在其允许的范围生成标识；固定 App ID 只允许将其指定标识分配给一个原应用，拒绝与原标识相同及站内另一个副本占用的情况。
- 副本与正常签名分别保存文件，源 IPA 不修改。元数据保留原标识、副本标识和名称，重签时不更换副本身份。
- 为匹配一个主应用描述文件，副本移除分享扩展、Widgets、Watch、App Clip、原自定义 URL scheme；保留主程序和框架。
- 签名前检查证书有效期、证书与描述文件匹配情况、应用标识范围和主程序加密状态。
- 不承诺绕过 iOS 签名限制、保留官方版数据或修复依赖原签名的登录、推送、内购。

## 下载任务

- 新增 paused、cancelled 状态及已认证的单任务控制接口，兼容旧客户端和旧服务器。
- Linux 使用独立进程组暂停/继续当前 ipatool 及其子进程，取消终止该组；Windows 安装隐藏不支持的暂停。
- 暂停排队任务不阻塞后面的新任务；暂停时保留临时文件，暂停时长不计入进程执行超时。
- 取消/删除与下载完成发布互斥；取消删除未完成文件，完成后的 IPA 留在文件列表。
- 删除队列中的任务不会令工作线程崩溃。任务仍只保存在内存，服务重启后不恢复；远端连接长时间暂停后可能失效，需重新下载。

## 验证

- Python 单元测试覆盖范围匹配、稳定标识、重签不漂移、源文件不变、ZIP 权限/完整性、本地化名称及组件移除。
- Linux 真实子进程测试覆盖暂停/恢复、暂停期间超时计算、取消暂停任务和其他任务不受影响。
- 使用隔离服务与确定的 CLI 替身，通过 HTTP 验证权限、任务状态、临时文件清理、队列存活及副本重签。
- GitHub Actions 构建服务端和 iOS；NAS 验证真实 ipatool 的暂停/继续及真实 zsign 的签名产物。手机实际安装由用户在设备确认。
